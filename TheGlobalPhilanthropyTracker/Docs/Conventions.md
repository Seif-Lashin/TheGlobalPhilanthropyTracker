1. C# Coding StandardsWe follow standard .NET naming conventions to keep the code readable and consistent.Classes & Methods: Use PascalCase. (e.g., UserRepository, CalculateImpact()).Variables & Parameters: Use camelCase. (e.g., contributionAmount, initiativeId).Private Fields: Use _camelCase with an underscore. (e.g., private string _connectionString).Constants: Use UPPER_SNAKE_CASE. (e.g., MAX_RETRY_ATTEMPTS).2. Windows Forms UI NamingTo avoid confusion in the "Drag and Drop" environment, never leave default names like button1.
